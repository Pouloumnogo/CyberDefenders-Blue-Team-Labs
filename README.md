## Featured Investigation

### 01 Phantom Installer: Blue Team Investigation

**Platform:** CyberDefenders  
**Category:** Digital Forensics & Incident Response  
**Status:** Completed

**Project Overview**

Investigated suspicious Windows executables and forensic artifacts to identify malicious activity, examine execution behavior, investigate persistence mechanisms, and analyze potential command-and-control (C2) activity.

**Tools Used:**
- FTK Imager
- Windows Event Viewer
- Detect It Easy
- dnSpy
- PowerShell and Command Prompt
- MFTECmd
- Timeline Explorer
- Windows Registry Analysis

**Skills Demonstrated:**
- Digital Forensic Investigation
- Malware Analysis
- Windows Artifact Analysis
- Threat Investigation
- Incident Response
- Timeline Reconstruction
- Indicators of Compromise (IOC) Identification
- Technical Documentation

**Investigation Evidence**

The project README contains screenshots documenting initial access, execution and AppDomain hijacking, persistence and C2, anti-forensics and destruction, and successful lab completion.
